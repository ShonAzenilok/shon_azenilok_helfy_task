# Shon's Task Manager

A simple task manager app with React frontend and Express backend.

## How to Run

### Backend setup

```bash
cd backend
npm install
npm start
```

The server runs on http://localhost:4000

### Frontend setup

Open a new terminal:

```bash
cd frontend
npm install
npm start
```

The app opens at http://localhost:3000

## API Endpoints
- GET /api/tasks
- POST /api/tasks
- PUT /api/tasks/:id
- DELETE /api/tasks/:id
- PATCH /api/tasks/:id/toggle
